✨ Características

Todo para operar con IA bajo control

Un agente con bucle de razonamiento propio, herramientas potentes y un diseño centrado en la seguridad.

🤖

Agente reasoning loop

Bucle de razonamiento autónomo que planifica, ejecuta herramientas y rectifica resultados en cada iteración.

🛡️

Control HITL

El humano valida cada acción crítica. El agente nunca actúa sin el permiso correspondiente en el bucle.

📁

Gestión de archivos

Leer, crear, editar y buscar en tu workspace: texto, binario, hex e incluso medios e imágenes.

🖥️

Navegador integrado

Chromium embebido con JavaScript, navegación, captura de pantalla y control completo del DOM.

⌨️

Control de escritorio

Captura de pantalla, clics de ratón y pulsaciones de tecla para automatizar aplicaciones locales.

⚙️

Comandos en paralelo

Ejecuta comandos del sistema y lanza tareas en segundo plano sin bloquear el hilo principal.

🎨

Interfaz PySide6

Diseño minimalista: prompt, tareas, historial y explorador del workspace organizados a la vista.

🔧

Local y Cloud

Modelos GGUF locales con llama-cpp-python, o cualquier API cloud compatible. Todo en config.ini.

🎯 Casos de uso

¿Para qué sirve Hercules?

Un agente versátil para flujos reales de trabajo asistido por IA.

01

Desarrollo asistido

Generar código, crear tests, depurar errores y refactorizar proyectos de extremo a extremo.

02

Orquestación multi-paso

Flujos en subtareas encadenadas (ANALIZAR → IMPLEMENTAR → COMPROBAR) con rectificación automática.

03

Automatización de escritorio

Controlar ratón, teclado y capturas para automatizar aplicaciones que no tienen API.

04

Investigación web

Navegar, extraer y sintetizar información manteniendo el control humano en cada paso.

05

Gestión de medios

Procesar archivos, imágenes y vídeos dentro de un workspace controlado y versionado.

06

Prototipos seguros

Probar agentes de IA en entornos locales con permisos paso a paso antes de pasar a producción.

Cómo funciona en la práctica

Tres escenarios reales de lo que Hercules es capaz de hacer.

Flujo completo Orquestador

Crear una web desde un README

El agente analiza la documentación, planifica las fases y construye el sitio sin intervención manual.

# Plan de subtareas (subtareas.ini)
[ANALIZAR]
prompt = Analiza el proyecto y lista sus partes

[IMPLEMENTAR]
prompt = Implementa {user_prompt}

[COMPROBAR]
prompt = Verifica que todo funciona
Con control humano HITL

Herramientas de escritorio aprobadas

Cada acción sensible requiere tu permiso. El agente propone, tú apruebas.

# Solicitud del agente
take_screenshot() → ⏳ Esperando permiso

mouse_click(x=100, y=200) → 🟢 Aprobado
En paralelo Rendimiento

Tareas en segundo plano

Lanza trabajos pesados sin bloquear la interfaz mientras sigues trabajando.

task_id = spawn_parallel_task(prompt)
# ... continúas tu trabajo ...
wait_parallel_task(task_id)

🚀 Instalación

Empieza en minutos

Requisitos: Python 3.11+ y PySide6. Funciona en Windows y Linux.

1

Clona el repositorio

git clone https://github.com/bondwell79/hercules.git
cd hercules
2

Instala las dependencias

pip install -r requirements.txt
3

Ejecuta el agente

python hercules.py

En Windows puedes usar el script run.bat.
