Bienvenido a Hercules.

Un agente para trabajar con modelos LLM: explora archivos, usa herramientas, navega por la web y coordina tareas mientras tú mantienes el control. Esta guía te lleva desde el primer arranque hasta un flujo de trabajo completo.

01 / Qué puedes hacer

De una pregunta a un flujo de trabajo.

Hercules combina un agente autónomo con herramientas para que tareas cotidianas y procesos de varios pasos ocurran desde una sola interfaz.

▤

Trabajar con archivos

Leer y buscar contenido, listar carpetas, crear archivos y editar texto dentro del workspace. También puede inspeccionar archivos binarios y adjuntar medios compatibles.

◎

Investigar en el navegador

Visitar páginas, leer su contenido, interactuar con controles, consultar la consola JavaScript y capturar una imagen del navegador integrado.

⌘

Ejecutar comandos

Lanzar comandos del sistema para inspeccionar el proyecto, automatizar operaciones o ejecutar herramientas que ya tengas instaladas.

⤢

Dividir y paralelizar

Delegar partes independientes en tareas paralelas, con límites configurables, seguimiento de resultados y cancelación controlada.

⌖

Controlar el escritorio

Con la dependencia opcional pyautogui, usar herramientas autorizadas para capturar pantalla e interactuar con ratón y teclado.

⟳

Adaptar el proceso

Definir fases de trabajo en subtareas.ini y ajustar modelo, límites, interfaz y otras opciones desde config.ini.

02 / Tutorial rápido

Tu primera tarea en cuatro pasos.

Empieza con un objetivo pequeño y un workspace conocido. Puedes ampliar el alcance cuando ya hayas revisado cómo trabaja el agente.

Inicia Hercules

En Windows, ejecuta run.bat. En otros entornos, instala los requisitos del proyecto y arranca desde la carpeta del repositorio:

python hercules.py

Comprueba el modelo

En config.ini, configura el modo de LLM (local o http) y los datos del proveedor o modelo. El modo local puede usar llama-cpp-python y un modelo GGUF.

Describe una tarea concreta

Indica el resultado que buscas, el contexto relevante y cualquier límite. Por ejemplo, empieza pidiendo un análisis sin cambios:

Revisa la estructura de este workspace,
resume sus componentes principales y sugiere
un plan. No modifiques archivos todavía.

Revisa la respuesta y sigue

Lee el resultado y afina la petición. Para una tarea posterior, puedes pedir cambios específicos; revisa las solicitudes de autorización antes de permitir acciones.

03 / Buenas prácticas

Autonomía con supervisión.

Hercules está diseñado para trabajar con el contexto del proyecto sin quitarte la capacidad de decidir qué acciones permitir.

✓

Revisa antes de autorizar

Las herramientas sujetas a autorización usan control humano en el bucle (HITL): puedes aprobarlas, preautorizarlas o cancelarlas según las opciones disponibles. La preautorización puede tener límites configurables; úsala solo cuando comprendas el alcance de las acciones.

Acota el workspace

Indica qué carpeta y archivos son relevantes. Para documentos locales, el navegador integrado limita el acceso al workspace.

Haz peticiones verificables

Especifica formato de salida, criterios de éxito y si quieres que el agente primero analice o proponga un plan.

Construye un flujo por fases

Configura subtareas.ini con prompts ordenados; usa {user_prompt} para incluir la petición original y referencias a resultados anteriores.

Listo para explorar.

Empieza con una tarea sencilla, observa qué herramientas propone Hercules y ve ajustando el flujo a tu manera de trabajar.
